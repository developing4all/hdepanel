# Building HDEPanel

## Quick Start

```bash
# Initial setup
mkdir build
cd build
qmake6 ../hdepanel.pro
cd ..

# Build (translations compile automatically!)
make

# Or from scratch
make qmake
make
```

## Build Commands

From the project root directory:

| Command | Description |
|---------|-------------|
| `make` | **Compile translations + build project** (default) |
| `make qmake` | Regenerate Makefiles from .pro files |
| `make lrelease` | Compile translations only |
| `make clean` | Clean build artifacts |
| `make distclean` | Remove all generated files |
| `make install` | Install to system (`PREFIX=/usr/local make install`) |
| `make help` | Show available targets |

## How It Works

The top-level `Makefile` is a wrapper that:
1. Automatically compiles translations (.ts → .qm) using `lrelease`
2. Then builds the project using the generated `build/Makefile`

### Translation Integration

Translations are defined in `hdepanel.pro`:
- **Input**: `translations/*.ts` (source translation files)
- **Output**: `translations/*.qm` (compiled translation binaries)
- **Tool**: `lrelease` (part of Qt)

The build system automatically:
- ✅ Finds the correct `lrelease` for your Qt version
- ✅ Compiles all `.ts` files to `.qm` files
- ✅ Shows "Compiling translations..." message
- ✅ Skips if translations are up-to-date

## Development Workflow

### Modify Code
```bash
# Edit source files
vim lib/panelwindow.cpp

# Build
make
```

### Update Translations

```bash
# Extract new translatable strings from code
lupdate -recursive . -ts translations/hdepanel_*.ts

# Edit translations (use Qt Linguist or edit .ts XML directly)
linguist translations/hdepanel_nl.ts

# Rebuild (translations compile automatically)
make
```

### Clean Build

```bash
make distclean
make qmake
make
```

## Dependencies

### Build-time
- Qt6 (Core, Widgets, DBus, WaylandClient)
- qmake6
- lrelease (part of Qt6 tools)
- g++/gcc
- make

### Runtime
- Qt6 libraries
- Wayland/X11 libraries
- Translation files (.qm) installed to `/usr/share/hdepanel/translations/`

## Installation

### Development Install
```bash
make
sudo make install
```

### Package Build (Debian)
```bash
dpkg-buildpackage -b -uc -us
```

The debian/rules file automatically:
1. Runs `qmake`
2. Compiles translations (`make lrelease`)
3. Builds the project (`make`)
4. Installs everything

## Troubleshooting

### Translations not updating?
```bash
# Force recompile translations
rm translations/*.qm
make
```

### Build fails after adding new files?
```bash
# Regenerate Makefiles
make qmake
make
```

### Qt tools not found?
```bash
# Ensure Qt6 development tools are installed
sudo apt install qt6-tools-dev qt6-tools-dev-tools qt6-l10n-tools
```

## Architecture

```
hdepanel/
├── Makefile              # Wrapper: auto-compiles translations
├── hdepanel.pro          # Main project (subdirs template)
├── build/                # Build directory (generated)
│   ├── Makefile         # Generated by qmake
│   ├── lib/             # Compiled library
│   ├── plugins/         # Compiled plugins
│   └── app/             # Compiled binary
├── lib/                  # Core library source
├── plugins/              # Plugin sources
├── app/                  # Main application
└── translations/         # Translation files
    ├── *.ts             # Source (editable)
    └── *.qm             # Compiled (auto-generated)
```
